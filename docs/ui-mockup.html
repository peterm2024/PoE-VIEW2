1
Navigation (QTreeWidget)

Charaktere + Stash-Ordnerbaum (rekursive children). Tab-Farbe aus der API als Farbpunkt. Klick löst einen FetchStashItems-Job im API-Worker aus; bereits geladene Tabs kommen aus dem Speicher-Cache.

2
Toolbar mit Liga-Wahl & Filter

Login-Status, manuelles Aktualisieren, Liga-Dropdown. Das Suchfeld filtert die Tabelle live und rein lokal — es kostet keine API-Requests.

3
Item-Tabelle (QTableView + SortFilterProxy)

Spalten sortierbar (Klick auf Kopfzeile), Rarity als Textfarbe (frameType), Icons asynchron aus dem Icon-Cache nachgeladen.

4
Item-Detail

Großes Icon, Name in Rarity-Farbe, Gem-Level/Quality aus dem properties-Array. Aktualisiert bei Zeilenauswahl.

5
Rate-Limit-Dashboard

Ein Balken pro Regel der aktiven Policy, gespeist vom Signal rate_limit_changed des RateLimitManagers (≙ LabVIEW User Event der FGV). Grün < 60 %, gelb < 90 %, rot in der Wartephase — inkl. Countdown, damit sichtbar ist, warum die App gerade pausiert.

6
Statusbar

Aktueller Job, Login-Status und der permanente GGG-Disclaimer.
